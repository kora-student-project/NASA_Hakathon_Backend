# Модуль супутникових даних NISAR

Бекенд не обробляє сирі знімки: він приймає лише готове зміщення. Цей модуль бере **реальні дані NASA NISAR**, рахує зміщення для кожного об'єкта і шле його в `POST /api/satellite/data`.

## Швидкий старт

```bash
pip install -r nisar/requirements.txt      # окремо від бекенду
```

1. Безкоштовний акаунт NASA Earthdata: https://urs.earthdata.nasa.gov → **Generate Token**.
2. У `.env` у корені репозиторію (файл у git не потрапляє) додайте:
   ```
   EARTHDATA_TOKEN=...
   API_URL=https://kora-backend-s5pq.onrender.com
   API_KEY_SATELLITE=...
   ```
3. Спершу лише пошук, без завантаження і відправки:
   ```bash
   python nisar/fetch_nisar.py run --dry-run
   ```
4. Реальний запуск (4 останні 12-добові пари для кожного об'єкта):
   ```bash
   python nisar/fetch_nisar.py run --max-granules 4
   ```

Корисні опції: `--object-id N`, `--since 2026-09-01`, `--group 28A` (траєкторія), `--no-post` (порахувати без відправки), `--download` (повністю завантажувати файли, якщо віддалене читання не працює), `inspect файл.h5` (показати структуру HDF5).

## Що відбувається

1. Бере об'єкти з бекенду (`GET /api/objects`).
2. Шукає в архіві ASF DAAC продукти **L2 GUNW** (розгорнуті інтерферограми, 12-добові пари), що накривають координати будівлі.
3. Файл GUNW важить ~2,4 ГБ, тож читається лише ділянка ~4×4 км навколо будівлі (HTTP range-запити).
4. Зміщення = (фаза в точці − медіана фази навколо, на відстані 300 м – 2 км) → міліметри вздовж лінії погляду (`d = −λ/(4π)·φ`, λ ≈ 23,8 см). Береться лише в межах одного компонента розгортання (`connectedComponents`).
5. Пари накопичуються по траєкторії (нуль = початок вибраного ланцюжка), кожна відправляється зі `source = "NASA NISAR GUNW track 28A"`.
6. Що вже оброблено, зберігається в `nisar/state.json` (у git не потрапляє), повторний запуск не дублює відправку.

Пари, які не пройшли перевірку якості (когерентність < 0.3, піксель поза областю розгортання, замало опорних пікселів), пропускаються з причиною в консолі.

## Обмеження (скажіть їх чесно)

- Дані NISAR L2 **PROVISIONAL** (попередні). Роздільність GUNW ~80 м: один піксель ≠ одна будівля.
- Зміщення **відносне** (до оточення) і **вздовж лінії погляду супутника**, а не строго вертикальне.
- Накопичення пар копить похибку; на полях і рослинності когерентність низька, на забудові краща.
- Атмосфера (вологість) дає мм-похибки, особливо влітку.
- **Віддалене читання HDF5 і точні назви шарів перевірені лише на синтетичному файлі** та на реальному пошуку. На реальному файлі їх треба перевірити першим запуском із токеном; якщо щось не так, `inspect` покаже структуру.
